# ADR-000 — Política de decisiones y cambios

Las ADR documentan cambios relevantes de ingeniería con fecha, contexto, opciones, riesgos, experimentos y resolución. Todas deben citar cómo afectan `ESPECIFICACION_MAESTRA_IA.md`, contratos, pruebas, backlog y migraciones. Un agente no debe cambiar el alcance por conveniencia sin una ADR y resultados.

Formato propuesto:

```
# ADR-NNN — Título
Fecha:
Estado: proposed | accepted | rejected | superseded
Contexto:
Opciones evaluadas:
Decisión:
Consecuencias y riesgos:
Evidencia/pruebas:
Impacto de migración:
```
