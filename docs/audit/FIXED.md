# Fixed audit findings

History of defects found and fixed, newest at the bottom. The full evidence
(tests, measurements and file references) is kept here; the open findings and
residual risks are in [`../AUDIT.md`](../AUDIT.md).

The values and paths in old rows describe the tree at the time of the fix.
`docs/` and `tests/` were reorganized in alpha.29.16.5, so a few paths in older
rows are historical names.
